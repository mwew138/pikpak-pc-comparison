## **PikPak PC版是什么——先搞清楚你的需求**

PikPak是一款私密云盘，核心能力是**云端下载**：你扔一个磁力链接、BT种子、或者Twitter/X视频链接进去，它的服务器帮你下好，存进你的私人云盘，然后你随时打开看、流媒体播放、或下载到本地。

整个过程跟你本地网速没太大关系——是PikPak的服务器在跑，速度极快，官网宣传80%以上的文件几秒内存入。

这事放在电脑端，就叫**PikPak PC版**。官方目前提供这几种PC端使用方式：

1. **Windows桌面客户端**（官方App）
2. **macOS桌面客户端**（支持Apple芯片M1及以上 / Intel芯片两个版本）
3. **浏览器网页版**（不用安装任何东西）
4. **Chrome扩展插件**（配合网页使用，最方便）

四种路子，各有各的用法，下面一个一个说清楚。

## **网页版vs桌面客户端——到底有什么区别？**

## **PikPak PC版核心功能：它能帮你做什么**

### 磁力链接/BT种子秒存

这是PikPak最核心的能力，也是很多人从迅雷或其他工具迁移过来的直接原因。

操作流程极其简单：
1. 在PC端（客户端或网页版）点"+"新建任务
2. 粘贴磁力链接（magnet:?xt=...）或上传.torrent文件
3. 提交，然后等——通常几秒到几十秒，文件就出现在你的云盘里了
4. 直接在线播放，或下载到本地

整个下载过程发生在PikPak服务器端，你本地网络只负责最后从云盘取文件，跟你的宽带上行没关系。ISP也看不到你在用磁力链接——官网说"所有服务器通信均使用加密协议"。

### 4K视频原画质在线播放

存进去的视频，可以直接在PC端在线播放，支持4K原画质。PikPak会自动提供多种分辨率选择，网络条件不好也能顺畅看。

相比国内一些网盘在线播放必须先转码的做法，PikPak保持了原始画质，看电影/纪录片体验明显更好。

> 注意：PC客户端目前还不支持HDR视频播放，如果你有HDR内容需要播，可以临时用手机App（Android 1.30+或iOS 1.11+支持HDR）。

### WebDAV支持

会员用户可以在网页版开启WebDAV功能，然后用任何WebDAV客户端（如Infuse、Nplayer、甚至Windows文件资源管理器）挂载PikPak云盘，像本地硬盘一样浏览文件。

这个对于NAS用户或喜欢折腾的人很有吸引力——PikPak本质上可以当一个"强化版远程NAS"来用。

### Telegram Bot联动

PC端不方便的时候，你还可以用Telegram Bot——把文件、链接直接发给Bot，它会帮你存到PikPak。等你打开电脑，文件已经在那儿了。多端无缝衔接的感觉挺好的。

## **传输配额是什么——别被这个吓着**

PikPak有月度传输配额这个设定，很多新用户看到会有点懵。

其实简单理解就是：每个月你能用的"数据量"上限。具体数字是：

- **云下载流量**：40 TB / 月
- **下行流量**（播放+下载到本地）：4 TB / 月
- **上传流量**：1 TB / 月

对于正常的个人用户来说，这个配额基本上是用不完的。官方也说了，只有在"非常极端的使用情况下"才会触及上限，比如你用它跑商业业务、大量转存分发之类的。

如果真的用超了，可以另外购买额外传输配额包（按流量单独付费）。
